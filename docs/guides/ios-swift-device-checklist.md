# iOS Swift 版真机验收清单

CI 只能证明「代码能编译、核心逻辑测试通过、IPA 结构完整」。下面这些项目必须在真机上由用户执行并记录。
没有记录前，不能把它们写成「已验证」。

记录方式：在「结果」列填 ✅ / ❌ / 部分，附日期、iOS 版本、App 构建号（「我的 › 关于」）和简短说明；需要时录屏。
